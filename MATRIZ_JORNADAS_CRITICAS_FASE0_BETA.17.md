# Matriz de jornadas críticas — Fase 0 — O Razão beta.17

**Data:** 28/10/2026. **Objetivo:** guiar teste manual reprodutível exigido pelo Plano Mestre.  
**Status global:** NÃO EXECUTADA EM BROWSER/ELECTRON REAL. As suítes de domínio e os testes de storage simulado são evidências parciais e não substituem esta matriz.

## Protocolo comum de execução

- Registrar versão, sistema operacional, navegador/Electron, resolução, tema, perfil, estado inicial e hash do arquivo fixture.
- Usar primeiro perfil vazio, depois perfil pequeno conhecido e depois dataset de pelo menos 5.000 lançamentos. Nunca usar dados bancários pessoais reais; fixtures sintéticas e anonimizadas.
- Registrar os saldos esperados por cálculo independente em planilha/fixture — saldo inicial + receitas pagas + transferências recebidas − despesas pagas − transferências enviadas, excluindo pendentes/canceladas e observando a data de corte.
- Após cada mutação, conferir UI, estado persistido após reload, trilha de auditoria, faturas e projeções. Se qualquer divergência for encontrada, parar e abrir bug reprodutível; não prosseguir para outra mutação com dados já divergentes.
- Exportar backup antes de casos destrutivos, validar checksum e guardar cópia externa de teste.

## Critério de aceitação de cada jornada

Uma jornada só pode ser marcada **PASSOU** depois de execução real documentada no ambiente designado, com versão/fixture, passos, resultado, screenshot/log aplicável e confirmação do saldo independente. Saída de teste unitário ou inspeção estática não serve para marcar jornada manual como concluída.
